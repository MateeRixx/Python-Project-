# 💡 RGB Light — Simple Desktop Color Display App

### 🌈 Turn your laptop into an RGB light instantly!

Hey there 👋  
I built this small tool to make my laptop act like an RGB lighting panel.

Earlier, I used to **download plain color images** from the web and open them in fullscreen —  
but that was slow and messy. So I made this app to save time and make color usage simple and fun 🎨

---

## ✨ Features

- 🟢 **Instant Color Display:** Pick any color and fill your entire screen with it  
- 🎨 **Circular Color Wheel:** Choose colors visually  
- 🔤 **HEX / Name Input:** Type colors like `#FF00FF` or `red`  
- ⚙️ **Saturation Control:** Adjust the color intensity with a slider  
- 🖥️ **Fullscreen Mode:** Instantly turn your laptop into a light source  
- 💾 **Lightweight:** No install needed — just run the `.exe`

---

## 🚀 How to Use

1. Go to the [**Releases**](https://github.com/your-username/rgb-light/releases) section  
2. Download the latest `.exe` file  
3. Run it — that’s it!  
4. Pick your color, adjust saturation, and hit “Fullscreen” for the perfect light.

---

## 🧠 Why I Made It

I often needed a solid background color while shooting or editing photos.  
Downloading and opening color images every time was tedious.  
This small app saves that hassle — just **pick, display, and create**.

> Hope it helps you too in your content creation journey 🌟
